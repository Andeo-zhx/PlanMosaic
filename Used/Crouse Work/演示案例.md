# PlanMosaic AI Agent 多步工具调用演示案例

> 本文档展示 PlanMosaic AI Agent 框架增强后的多步工具调用能力。每个案例模拟用户真实输入，展示 Agent 如何通过 **ReAct（Reasoning + Acting）** 范式，自动编排多个工具的调用链，最终产出结构化、可落地的结果。

---

## 案例一：查资料 + 排日程

**涉及工具链：** `web_search_evaluate` → `view_schedule` → `add_schedule`

**场景类型：** 信息检索 + 日程管理

### 用户输入

> 帮我查一下番茄工作法的最佳实践，然后在我明天下午安排两个番茄钟时段

### ReAct 转录

```
Question: 帮我查一下番茄工作法的最佳实践，然后在我明天下午安排两个番茄钟时段

Thought: 用户想了解番茄工作法的最佳实践，我需要先搜索相关资料。
Action: web_search_evaluate(query="番茄工作法 最佳实践", purpose="最佳实践", max_results=5)
Observation: [搜索结果：1.番茄工作法核心是25分钟专注+5分钟休息，每4个番茄钟后休息15-30分钟；2.适用场景：写作、编程、学习等需要深度专注的任务；3.关键技巧：关闭手机通知、使用物理计时器、任务开始前明确目标...]

Thought: 已经了解了番茄工作法的要点。现在我需要查看明天下午的日程，确保有空闲时段。
Action: view_schedule(date="明天日期")
Observation: 明天下午14:00-15:30已有"团队会议"；16:00-16:45已有"代码评审"

Thought: 明天下午15:30-16:00之间有30分钟空闲，之后16:45后空闲。根据番茄工作法，每个番茄钟25分钟，两个番茄钟需要约1小时（含5分钟休息）。我安排在16:45-17:10和17:15-17:40两个时段。
Action: add_schedule(date="明天日期", timeSlots=[
  {"time":"16:45-17:10","activity":"番茄钟时段1","detail":"25分钟专注","icon":"🍅"},
  {"time":"17:15-17:40","activity":"番茄钟时段2","detail":"25分钟专注","icon":"🍅"}
])

Final Answer: 已为你明天下午安排了两个番茄钟时段！根据番茄工作法最佳实践：16:45-17:10第一个番茄钟，休息5分钟后17:15-17:40第二个番茄钟。专注时记得关闭手机通知、使用计时器、保持环境安静，效率翻倍哦～🍅
```

### 关键点总结

| 步骤 | 工具 | 作用 |
|------|------|------|
| 1 | `web_search_evaluate` | 获取番茄工作法的关键参数（25分钟/5分钟） |
| 2 | `view_schedule` | 检查明天下午的空闲时段，避免冲突 |
| 3 | `add_schedule` | 基于搜索结果 + 空闲时段，智能安排两个番茄钟 |

## 案例二：时间估算 + 任务拆解

**涉及工具链：** `estimate_task_time` → `view_schedule` → `manage_big_tasks(break_down)`

**场景类型：** 学习规划 + 时间管理

### 用户输入

> 我下周一要交一个2000字的实验报告，帮我规划一下

### ReAct 转录

```
Question: 我下周一要交一个2000字的实验报告，帮我规划一下

Thought: 用户需要写一份2000字的实验报告，截止下周一。我需要先估算这需要多长时间。
Action: estimate_task_time(task_name="写2000字实验报告", category="学习", context="下周一截止")
Observation: 基于模型估算，预计需要约360分钟（6小时），建议分3-4次完成

Thought: 6小时无法一次完成，需要查一下本周空余时间，拆分为多个子任务。
Action: view_schedule(list_all=false, keyword="本周")
Observation: [本周空闲时段：今天晚上2小时，明天下午3小时，周六上午3小时，周日下午2小时]

Thought: 好的，合理分配：今天查资料+大纲，明天写主体，周六上午修改，周日下午定稿。
Action: manage_big_tasks(action="break_down", task_name="实验报告", subtasks=[
  {"name":"查资料+列大纲","date":"今天","estimated_minutes":90},
  {"name":"撰写初稿（1200字）","date":"明天","estimated_minutes":150},
  {"name":"补充完善（800字）+修改","date":"周六","estimated_minutes":120},
  {"name":"定稿润色+提交","date":"周日","estimated_minutes":60}
])

Final Answer: 已为你规划好实验报告写作计划！基于时间估算模型，2000字报告约需6小时。拆分为4个子任务：今天（大纲90分钟）→ 明天（初稿150分钟）→ 周六（修改120分钟）→ 周日（定稿润色60分钟）。完成每步后在任务中记录实际用时，帮助Mosa未来更精准估算～
```

### 关键点总结

| 步骤 | 工具 | 作用 |
|------|------|------|
| 1 | `estimate_task_time` | AI 模型估算任务总耗时（360分钟） |
| 2 | `view_schedule` | 检索本周空闲时段，匹配可用时间窗口 |
| 3 | `manage_big_tasks` | 将大任务按空闲时段拆解为4个可执行的子任务 |

## 案例三：搜索 + SWOT + 决策矩阵（深度规划模式）

**涉及工具链：** `web_search_evaluate` → `swot_analysis` → `swot_analysis` → `decision_matrix`

**场景类型：** 战略决策 + 多维度分析

### 用户输入

> 我在纠结考研还是直接工作，帮我分析一下

### ReAct 转录

```
Question: 我在纠结考研还是直接工作，帮我分析一下

Thought: 这是战略决策问题，需要先了解当前行业形势，然后对两个选项分别进行SWOT分析，最后用决策矩阵对比。
Action: web_search_evaluate(query="计算机专业 考研vs就业 2025", purpose="形势分析", max_results=5)
Observation: [搜索结果：1.2025年计算机行业就业形势：AI人才缺口大，但基础开发岗位竞争加剧；2.考研趋势：CS相关专业报录比持续走高，985/211院校复试线普遍上涨；3.学历对薪资的影响：硕士起薪平均比本科高30%-50%，但3年工作经验可弥补差距...]

Thought: 信息收集完成。现在分别对考研和直接工作进行SWOT分析。
Action: swot_analysis(subject="考研", user_context="计算机专业本科生", focus_area="career")
Observation: [SWOT: 优势-学历提升/专业技能深化/导师资源/校园招聘优势；劣势-时间成本3年/经济压力/学术与工业界脱节风险；机会-高薪研发岗位/AI算法岗学历门槛/人才引进政策；威胁-学历贬值趋势/政策变化/同龄人已积累3年经验]

Thought: 继续分析直接工作的选项。
Action: swot_analysis(subject="直接工作", user_context="计算机专业本科生", focus_area="career")
Observation: [SWOT: 优势-3年工作经验/经济独立/实战能力提升/行业人脉积累；劣势-起薪较低/系统学习时间少/部分岗位学历天花板；机会-行业风口/AI应用层爆发/创业机会/内部晋升通道；威胁-晋升天花板/技术迭代快需持续学习/裁员风险/学历在跳槽时可能成为短板]

Thought: 两个选项的SWOT分析都已完成，现在用决策矩阵进行量化对比。
Action: decision_matrix(decision_topic="考研 vs 直接工作", options=["考研","直接工作"], criteria=["职业发展空间","经济收益","时间成本","个人兴趣匹配","风险可控性"], context="计算机专业本科，对AI方向有兴趣")

Final Answer: 综合分析如下：
【考研】综合评分4.2/5.0：学历长期价值高，AI研究岗位门槛高，3年时间投入换更多选择权；
【直接工作】综合评分3.8/5.0：经济独立快，实战经验丰富，但晋升可能受限。
建议：如果对AI研发有强烈兴趣且家庭经济可支撑，考研是更优选择；如果想快速积累行业经验和资金，先工作1-2年再根据需求决定是否读研也不错。
```

### 关键点总结

| 步骤 | 工具 | 作用 |
|------|------|------|
| 1 | `web_search_evaluate` | 检索 2025 年计算机行业考研与就业形势数据 |
| 2 | `swot_analysis`（考研） | 对考研选项进行优势/劣势/机会/威胁四维分析 |
| 3 | `swot_analysis`（直接工作） | 对工作选项进行对称的SWOT分析 |
| 4 | `decision_matrix` | 基于 SWOT 结果，用量化评分矩阵进行最终对比决策 |

### 深度规划模式说明

案例三展示了 PlanMosaic **深度规划模式（Deep Planning Mode）** 的核心能力：

- **多轮信息收集**：先搜索外部信息，而非直接臆断
- **对称分析**：对互斥选项逐一进行 SWOT 分析，确保公平对比
- **量化决策**：通过决策矩阵将定性分析转化为定量评分，降低主观偏差
- **可解释性**：每一步的 Thought/Action/Observation 完整记录，决策过程透明可追溯
